# Лабораторная работа № 3

**Дисциплина:** Платформы и среды ЯП.

**Тема:** статические и динамические библиотеки, порядок компоновки и связывание C с C++.

## Задача A. Как пройти в библиотеку?

В работе математический модуль на C собирается сначала в статическую библиотеку `.a`, затем в динамическую библиотеку `.so` и связывается с программой на C++. Дополнительные эксперименты показывают влияние `-fPIC`, порядка аргументов компоновщика, `--as-needed` и языкового связывания `extern "C"`.

## Проверка результатов

Работа воспроизводится в Linux x86-64 с GCC и GNU binutils. Сценарий создаёт все объектные файлы, библиотеки и программы в игнорируемом каталоге `build/`, проверяет ожидаемый вывод программ и завершает работу строкой `ALL CHECKS PASSED`.
