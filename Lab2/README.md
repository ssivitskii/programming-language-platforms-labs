# Лабораторная работа № 2

**Дисциплина:** Платформы и среды ЯП.

**Тема:** анализ ELF-файлов, секций и символов; разрешение конфликтов при линковке.

## Задача A. Избавьтесь от легаси

Исследуются размеры секций объектных файлов, строки и таблицы символов, поведение COMMON-символов и способы исправления конфликта `system_mode`.

## Исходные объектные файлы

[core.o](core.o), [legacy.o](legacy.o), [hotfix.o](hotfix.o) и [main.o](main.o) предоставлены в составе задания и сохранены для воспроизведения анализа. Исходного кода модулей `core`, `legacy` и `main` в комплекте нет.

## Проверка результатов

Работа выполняется в Linux x86-64 с GCC и GNU binutils. При пересборке `hotfix.c` с `-fno-common` ожидается ошибка `multiple definition`: она демонстрирует исследуемый конфликт. Далее сценарий собирает варианты с `extern` и `static`; различия в их поведении разобраны в отчёте.
